Agent Plugins Specification v1.0.0, published by the Agent Plugins project, defines a portable directory package with plugin.json and optional Agent Skills under skills and MCP server configuration in mcp.json. The normative package paths must stay within the resolved plugin root. The format packages reusable components but does not itself sandbox a plugin subprocess or restrict runtime paths.
