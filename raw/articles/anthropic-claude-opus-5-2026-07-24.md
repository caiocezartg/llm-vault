## Excerpt

Anthropic announced Claude Opus 5 on 24 July 2026. The model is available as `claude-opus-5` on the Claude API at US$5 per million input tokens and US$25 per million output tokens; Fast mode is priced at twice the base rate. The announcement describes improved coding and computer-use results, but its charts and early-access customer reports are vendor evidence.

Anthropic states that some cyber-related requests can be routed to Opus 4.8 by default when safeguards trigger; API users can enable automatic fallback. Claude Code v2.1.219 makes Opus 5 the default Opus model, adds a 1M-context label, and adds `sandbox.network.strictAllowlist` for sandboxed commands.
