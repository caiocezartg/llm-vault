GitHub announced Dynamic Workflows for Copilot CLI, the Copilot app and the Copilot SDK on 1 October 2026. A workflow is extension code that defines sequential and parallel steps, structured handoffs, tools/services, subagent cross-checks, human-input points and pause/resume checkpoints; agents perform the judgment-bearing portions. GitHub distinguishes this code-defined execution from Autopilot and /fleet. The feature is available on all Copilot plans but remains public preview; the CLI requires experimental mode. GitHub provides no benchmark proving that dynamic workflows improve quality, safety or cost. An independent technical recap confirms that operational limits and pre-authorized tool permissions remain consequential, so workflow code is orchestration, not an authorization or acceptance boundary.
