# DeepSeek-V4.1-Flash-1017: official release record

**Source:** https://api-docs.deepseek.com/news/news261017/
**Captured:** 2026-10-18

DeepSeek announced DeepSeek-V4.1-Flash-1017 on 17 October 2026. The vendor states that the checkpoint is live on its web, app and API surfaces; it is optimized for DeepSeek Harness and listed as an open-source release on Hugging Face and ModelScope.

The vendor claims higher benchmark performance, faster task completion and shorter outputs than the prior V4.1 Flash checkpoint. Its release specifically reports evaluation through the Mini-SWE-V2 harness for DeepSWE v1.1; those comparative performance and cost statements remain vendor evidence.

The associated Hugging Face model card declares MIT licensing for the repository and weights, a 763B-parameter model, BF16/F32/F8_E4M3/I8 tensors, and a reference prompt-encoding implementation covering multi-turn conversations, tool calls, thinking mode, numeric reasoning effort, mid-conversation system messages and interleaved image content. It also documents local-inference conversion instructions and recommends a 1M-token context window with at least 256K maximum tokens. The card says model inference, tool execution and HTTP transport are left to the caller.

The 1017 card reports 42.3 on Terminal-Bench 4.0 and 77.0 on DeepSWE v1.1, versus 31.2 and 74.2 for the prior V4.1 Flash respectively. These results were reported by DeepSeek; they are not an independent coding-agent evaluation.

The same release opened Search & Fetch APIs. The vendor says each endpoint costs $0.75 per 1,000 calls, and that server-side calls from DeepSeek Harness, Claude Code and Codex are free to DeepSeek API users until billing begins on 31 October 2026 at 16:00 UTC.
