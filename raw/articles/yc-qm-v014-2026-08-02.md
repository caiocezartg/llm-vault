# QM v0.1.4 — primary release and repository documentation

QM is an MIT-licensed, open-source multiplayer agent harness for work. The primary repository describes per-person and per-room scopes for memory, files, keychain view, permissions, crons, web apps, and durable sandboxes.

The repository states that deployments can select Pi, OpenCode, Codex, or Claude Code against the same core. Its central core uses TypeScript on Node, Fastify, and Postgres for sessions, memory, and queueing; each scope has an isolated sandbox.

Release v0.1.4 was published on 2026-07-31. It restricts the web UI model picker to the organization allowed-model list and changes qm init bootstrap to use @latest. The project documentation describes Strict, Auto, and Dangerous postures, while preserving predeclared command policy across them.
