# GitHub Copilot: selected-model deprecation on 2026-10-19

Source URL: https://github.blog/changelog/2026-09-18-upcoming-deprecation-of-selected-github-copilot-models-in-mid-october/
Retrieved: 2026-09-19

GitHub announced that Gemini 3.7 Flash, GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini and Grok 4.5 will be deprecated across GitHub Copilot experiences on 2026-10-19. GitHub suggests Gemini 3.8 Flash, GPT-5.6 Sol, GPT-5.6 Luna and Grok 4.6 as successors.

The announcement tells teams to update workflows and integrations before the date. Under default model enablement, suggested alternatives are automatically enabled for Business and Enterprise customers unless administrators have disabled the global default or the model policy. This is a compatibility/migration statement, not evidence that substitutions preserve cost, quality, tool behavior or policy compliance.
