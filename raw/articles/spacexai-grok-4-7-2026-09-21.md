# Introducing Grok 4.7

Source URL: https://x.ai/news/grok-4-7
Retrieved: 2026-09-22

SpaceXAI announced Grok 4.7 on 2026-09-21 as a new, larger base model for coding and knowledge work. The vendor says it was trained longer with reinforcement learning on a harder task mix weighted toward multi-hour tasks, with stronger self-verification and longer-context management.

The official comparison lists the same $2 per million input and $6 per million output token pricing as Grok 4.6, with a 500k-token context window. It reports 46.3% on CursorBench 4.0, 71.0% on DeepSWE v1.1 at high effort, and 38.0% on Terminal-Bench 4.0. These are first-party benchmark claims.

The announcement says Grok 4.7 is available through Grok Build, the Grok API, Cursor, third-party coding harnesses, model routers, cloud platforms, and (separately) GitHub Copilot's gradual rollout. It also claims a new safeguard stack and describes restricted cybersecurity red-team access.
