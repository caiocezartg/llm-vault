DwarfStar 4 (ds4) is an MIT-licensed C inference engine from Salvatore Sanfilippo for selected large open-weight models on Metal, CUDA and ROCm. Its public documentation currently lists DeepSeek V4/V4.1 Flash, GLM 5.x and Qwen 3.8 variants, a CLI, local OpenAI/Anthropic-compatible APIs and clients for Pi, OpenCode, Codex CLI and Claude Code. The project documents asymmetric low-bit quantization, disk-resident KV cache, SSD streaming and tensor parallelism; its published throughput table is a project baseline, not an independent benchmark. On 3 October 2026, its GitHub repository reported 23,024 stars, 2,218 forks and 797 commits; it had no tagged releases. A current Hacker News thread recorded 221 points and 56 comments, including both early integrations and hardware/support limitations.
