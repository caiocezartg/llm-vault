# GLM-5.3-Flash — official model-card excerpt

Z.ai's Hugging Face model card presents GLM-5.3-Flash as the first natively multimodal GLM-5 model. It states 320B total parameters with 18B active, a hybrid sparse-and-linear-attention design, a 30T-token multimodal pre-training corpus, and an intended focus on coding and long-horizon agent workloads.

The card documents local deployment paths for SGLang, vLLM, TokenSpeed, Transformers, KTransformers and Unsloth. It also cautions that several reported evaluations use particular harnesses, sampling settings, long contexts and/or an LLM judge; those results should not be treated as directly comparable to a different coding-agent harness.
