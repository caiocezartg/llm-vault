# OpenAI Agents API — bounded primary capture

OpenAI announced the Agents API public beta on 2026-09-10. It exposes a managed Codex harness through sessions and supports OpenAI-hosted, self-hosted, and partner environments, plus built-in, custom, and MCP tools. The surface includes context management, automatic compaction, tool search, programmatic tool calling, and optional multi-agent work.

The service does not make authorization, secrets, network policy, environment containment, acceptance criteria, or observability someone else responsibility. Teams must verify those boundaries in the selected environment and keep independent gates outside the managed harness.

The launch is public beta. Early coverage independently confirms the deployment choices and notes availability/retention limitations; it is not evidence of outcome quality or broad production adoption.
